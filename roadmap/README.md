# C# Karaoke Challenges Roadmap

This folder contains the working roadmap for the C# Karaoke Challenges project.

The roadmap is intended as a guide rather than a fixed plan. Challenge titles, ordering and scope may change as the series progresses depending on what needs more practice and which features make the most sense to build next.

## Roadmap Structure

The current roadmap progresses through:

1. Foundations
2. Metadata
3. Library Features
4. Persistence
5. Application Architecture
6. Player

Milestone and refactoring challenges are included throughout so earlier work can be combined and improved rather than remaining as isolated exercises.

## Challenge Identifiers

Challenges use the format `#NNN`, for example `#001`, so spreadsheet applications preserve the leading zeros.
