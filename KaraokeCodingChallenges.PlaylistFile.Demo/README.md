# M3U Playlist Demo

Manual verification application for Challenge 027 - M3U Playlist Import & Export.

## Verification

The demo:

- Creates a `MediaPlaylist`.
- Adds real audio tracks.
- Exports the playlist to an M3U file.
- Reads the generated playlist back into the application.
- Displays the imported playlist name and track paths.

The generated M3U playlist was successfully opened in:

- VLC Media Player
- Winamp

This confirms that the exported playlist is compatible with external media players.
